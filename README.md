# Image Gallery

A responsive Image Gallery built using HTML, CSS, and JavaScript with interactive navigation and category filtering.

## Features

- Responsive image grid layout
- Hover effects and smooth transitions
- Lightbox image preview
- Previous / Next navigation
- Keyboard navigation support
  - Left Arrow (Previous)
  - Right Arrow (Next)
  - Escape (Close)
- Click outside image to close modal
- Category filtering
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS
- JavaScript

This project was developed as part of the CodeAlpha Front-End Development Internship.
